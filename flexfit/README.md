# FlexFit

A Next.js + Tailwind starter for the creator subscription + challenge platform.

## Quick start

1. Install dependencies
   ```bash
   npm install
   ```
2. Run the dev server
   ```bash
   npm run dev
   ```
3. Open http://localhost:3000

## Tech
- Next.js (App Router, TypeScript)
- Tailwind CSS
